# Fake-News-Prediction

This project aims to build a machine learning model capable of predicting whether a news story is false or true based on its content.
The data will be pre-processed for cleaning and preparation for analysis, and since it contains text, natural language processing (NLP) techniques will be applied.
I will use techniques such as stemming and stopword removal to pre-process the textual data and convert it into a numerical format using TF-IDF vectorization.
In this way, we can extract relevant features from the textual data.
For this project, we will use the Logistic Regression model. I chose this model because it is simple, interpretable, and effective for binary classification tasks.
The project will use Python and popular libraries such as pandas, scikit-learn, and nltk.
The final model will be evaluated for accuracy and used to make predictions about new news stories.
